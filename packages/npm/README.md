# @loveteemo/quickhide

quickHide 的 GitHub Packages 发布通道，包内含对应版本的 `quickHide.exe`（Windows 可执行文件）。

- 主仓库与文档：https://github.com/loveteemo/quickHide
- 版本与 Release：https://github.com/loveteemo/quickHide/releases

安装（需 GitHub Packages 认证，参考 [GitHub Packages 文档](https://docs.github.com/packages/working-with-a-github-packages-registry/working-with-the-npm-registry)）：

```
npm install @loveteemo/quickhide@0.1.31 --registry=https://npm.pkg.github.com
```
